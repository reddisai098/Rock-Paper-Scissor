# Rock-Paper-Scissor

A sleek, responsive, and interactive browser-based Rock Paper Scissors game built with vanilla web technologies.

---

## 🎮 Features
- **Clean UI:** Rounded circular controls and interactive hover animations.
- **Smart Opponent:** Randomized computer move selection logic.
- **Real-Time Results:** Instant outcome tracking for wins, ties, and losses.
- **Zero Dependencies:** Pure vanilla JavaScript, CSS, and HTML without external libraries.

---

## 🛠️ Built With
- **HTML5:** Semantic game structuring.
- **CSS3:** Flexbox layout, smooth transitions, and custom border stylings.
- **JavaScript (ES6):** Core game mechanics, random choice generation, and DOM manipulation.
